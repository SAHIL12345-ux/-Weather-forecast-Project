# 🌦 Weather App

A simple and modern weather application built using **HTML, CSS, and JavaScript**.  
This app fetches real-time weather data from the **OpenWeather API** and displays temperature, humidity, and weather conditions using emojis.

---

## 🚀 Features
- 🔍 Search weather by city name
- 🌡 Temperature displayed in Celsius
- 💧 Humidity information
- 🌤 Weather condition emojis
- 🌙 Dark mode toggle
- ❌ Error handling for invalid city names

---

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API
